# AcroStella Analytics

Instaladores Android y paquetes iOS para firma. El código fuente y los vídeos permanecen privados.

- **Android:** descarga el APK en la [última versión estable](https://github.com/tecnofifamobile-ai/AcroStella-Updates/releases/latest). Desde 0.3.0 las actualizaciones se ofrecen dentro de la app.
- **iPad/iPhone:** [IPA 0.4.0 sin firma](https://raw.githubusercontent.com/tecnofifamobile-ai/AcroStella-Updates/refs/tags/ios-v0.4.0%2B4/acrostella-analytics-0.4.0%2B4-unsigned.ipa). Importar en Flarestore y firmar con certificado/perfil válidos antes de instalar. Las versiones iOS figuran como prereleases para mantener separado el canal Android.

La IPA sin firma no se instala directamente desde Safari. Certificado, perfil y funcionamiento físico requieren validación en el dispositivo.

## Fuente para Flarestore

Añade esta URL como source (formato AltStore):

```text
https://raw.githubusercontent.com/tecnofifamobile-ai/AcroStella-Updates/main/flarestore.json
```

La fuente ofrece la IPA sin firma. Descárgala desde Flarestore y fírmala con tu certificado y perfil antes de instalar. La importación y la instalación física están pendientes de verificar en el dispositivo. La URL de la fuente se mantiene para futuras versiones; cada IPA apunta a una etiqueta fija.
